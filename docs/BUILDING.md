# Building

The patch is one addon, `addons/main`, built into `a3bal_main.pbo` by
[HEMTT](https://hemtt.dev). Its config is generated by the pipeline
(`tools/a3bal.py release`); don't edit it by hand, or the provenance in
`release.json` stops matching.

## Install HEMTT

Download `windows-x64.zip` (or the Linux build) from the
[HEMTT releases](https://github.com/BrettMayson/HEMTT/releases) and put
`hemtt.exe` on your PATH. The project was tested with HEMTT 1.22.0.

Arma 3 Tools are optional. Without them HEMTT prints a `BBW1` warning and still
builds; nothing in this addon needs binarizing beyond the config, which HEMTT
does itself.

## Build

```powershell
hemtt build
```

Output: `.hemttout/build/addons/a3bal_main.pbo`, plus `mod.cpp`. Add
`.hemttout/build` as a local mod in the launcher to try it.

Expected diagnostics:

- `L-C12 Math could be unquoted`: some mods write armor as `"22+ 3"`. The
  patch keeps their text exactly, and the game evaluates it.
- `L-C14 unused external classes`: parent classes declared to keep the
  inheritance tree intact. Harmless.

## Release and sign

```powershell
hemtt release
```

This builds, signs the PBO and zips the mod into `releases/`. HEMTT generates a
signing key for the version and puts the `.bikey` in `.hemttout/release/keys/`.
Put that `.bikey` in the server's `keys` folder. Players load the signed folder
from the zip.

To keep one key across versions, create a private key once and keep it out of
git (`.gitignore` already excludes `*.biprivatekey` and `.hemttprivatekey`). See
HEMTT's signing documentation for `.hemttprivatekey`.

To release a new version, bump `addons/main/script_version.hpp` first.

## Without HEMTT

`tools/build_release.py` packs an uncompressed, unsigned PBO with a text config,
the same format the verified test mod used:

```powershell
cd tools
python build_release.py validation/session --pilot balance-pilot --out release
```

That writes `tools/release/@A3Balance`. Sign it with Arma 3 Tools' DSSignFile if
the server checks signatures.

## About the config

`addons/main/config.cpp` is the tested pilot's config with only the
`CfgPatches` entry renamed (`a3bal_pilot` to `a3bal_main`). One more change is
made for HEMTT: its parser rejects no-break spaces, so the two found in one
mod's vest description are written as normal spaces. `release.json` records
the pilot build ID, the hash of the tested config and the number of characters
replaced.

HEMTT binarizes the config into `config.bin`. To check it, unpack the built PBO
(`hemtt utils pbo extract .hemttout/build/addons/a3bal_main.pbo config.bin`),
derapify it (`hemtt utils config derapify config.bin`) and compare. For this
release, all 193,581 entries matched the source.
